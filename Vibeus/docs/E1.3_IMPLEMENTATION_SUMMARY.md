## Technical Details

### Implementation Architecture

**Beat Detection Algorithm:**
```cpp
// Peak-based detection (main.cpp line 1421-1435)
float currentPeak = g_audio.levelPeak();
static float beatThreshold = 0.3f;
static int beatCooldown = 0;

// Cooldown prevents double-triggering
if (beatCooldown > 0) beatCooldown--;

// Trigger on peak above threshold
if (currentPeak > beatThreshold && beatCooldown == 0 && currentPeak > 0.1f) {
    g_beatIndicatorAlpha = 1.0f;
    beatCooldown = static_cast<int>(g_currentFps * 0.25f); // 250ms
}

// Adaptive threshold adjusts to music volume
beatThreshold = beatThreshold * 0.98f + currentPeak * 0.02f + 0.04f;
```

**Visual Rendering:**
```cpp
// menu_overlay.cpp line 231-235
ImGui::GetBackgroundDrawList()->AddCircleFilled(
    ImVec2(50, 50),  // Top-left position
    20,              // 20px radius
    ImColor(1.0f, 0.0f, 0.0f, alpha)  // Red with fade
);
```

**Fade Animation:**
```cpp
// main.cpp line 1438-1442
if (g_beatIndicatorAlpha > 0.0f) {
    float deltaTime = 1.0f / g_currentFps;
    g_beatIndicatorAlpha -= deltaTime * 4.0f;  // 4x fade speed = ~250ms
}
```

### Key Features

1. **Adaptive Threshold:** Automatically adjusts to music volume
2. **Cooldown Period:** 250ms between triggers prevents false positives
3. **Smooth Fade:** 4-second decay for pleasant visual effect
4. **Low FPS Handling:** Cooldown minimum of 15 frames for 30 FPS mode
5. **Non-intrusive:** Small red circle in top-left corner

## Known Limitations

1. **Peak-based detection only**
   - Uses `levelPeak()` instead of `levelBeatBass()`
   - May miss bass-only beats in complex mixes
   - Future: Use isolated kick detection (<150Hz)

2. **Hardcoded visual design**
   - Position: (50, 50) fixed
   - Color: Red only
   - Size: 20px radius
   - Future: Add customization options

3. **Not configurable**
   - No config.json persistence (resets on restart)
   - Future: Add `showBeatIndicator` to VibeusConfig
